**In one paragraph:** a `*.pspec` file declares each input with a SEMANTIC_MODEL term, a basis, and `once` or `turn`. It declares the output form with `out`, and holds template sections in a small Jinja-like syntax. The `{% v %}…{% c %}…{% end %}` switch selects the verbatim text or the compact text. Three things come from one file: `compile(spec, section, values, mode)`, `check(spec, answer, values)`, and `tokens(text)`, which is `ceil(utf-8 bytes / 4)`. The model's answer is an Opinion; `check` and the deterministic rules after it decide.
